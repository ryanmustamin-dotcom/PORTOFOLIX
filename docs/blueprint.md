# **App Name**: ArtSphere

## Core Features:

- User Profile Management: Users can register, create a personalized profile, upload an avatar, and manage their portfolio information.
- Project Upload & Display: Creators can upload various media (images, videos, PDFs) for their projects, add titles, detailed descriptions, and assign categories/tags.
- Personalized Portfolio Pages: Each user gets a dedicated public-facing page to showcase all their uploaded projects in an organized gallery format.
- Project Discovery & Search: Browse projects by category, trending status, or utilize a search function to find specific projects or creators by keywords.
- AI-Enhanced Project Descriptions: An AI tool that suggests relevant tags, keywords, or provides an initial draft for project descriptions based on uploaded content (e.g., image analysis or brief user input).
- Like & Comment System: Users can 'like' projects and leave comments, fostering community interaction.
- Secure Data & Media Storage: Robust and secure storage for all user profiles, project metadata, and media assets.

## Style Guidelines:

- Primary color: `#3377CC` (a serene, thoughtful blue), used for interactive elements and key accents. Chosen to evoke professionalism and creativity without being overly bold. A slightly dark scheme will make artwork pop.
- Background color: `#20252B` (a desaturated, dark blue-gray), providing a sophisticated backdrop that helps vibrant artwork stand out. The hue is consistent with the primary color, offering a cohesive visual experience.
- Accent color: `#55CCDD` (a bright, crisp cyan-blue), offering strong contrast for calls to action, highlights, and subtle interactive cues, approximately 30 degrees from the primary for harmonious variety.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, slightly tech-inspired aesthetic, ideal for project titles and prominent text.
- Body text font: 'Inter' (sans-serif) for high readability across all screen sizes, complementing 'Space Grotesk' with its neutral and objective character, perfect for descriptions and general interface text.
- Utilize modern, clean line icons that convey functionality intuitively, ensuring consistency with the overall minimalist and professional design.
- A responsive, adaptive grid-based layout for showcasing projects, optimized to display visual content prominently across diverse devices. Emphasis on clean separation and balanced white space.
- Subtle, non-intrusive animations for transitions between pages and smooth hover effects on project cards, enhancing user experience without distracting from the creative content.
